1. พยากรณ์ = ต่อเส้นจากอดีต — ด้วยเครื่องมือง่าย ๆ สามตัว¶

เราจะไม่พึ่งเวทมนตร์ใด ๆ — ทั้งหมดคือคณิตมัธยมปลายที่คอมพิวเตอร์คำนวณให้:

เครื่องมือ ทำอะไร เมื่อไหร่ใช้
trend line เส้นตรงที่พอดีข้อมูลมากที่สุด แนวโน้มระยะยาว
moving average เฉลี่ยข้างเคียง n จุด เลื่อนไปเรื่อย ๆ กรองเสียงรบกวนให้เห็นทิศ
วงรอบ ความซ้ำที่มาทุกช่วงเวลาเท่ากัน ฤดูกาล/เทศกาล

และกติกาประจำโมดูล: ทุกการพยากรณ์ต้องผ่านการตรวจ — เราจะซ่อนช่วงท้าย ข้อมูลไว้ ให้เส้นทำนาย แล้วเทียบกับของจริง ก่อนเชื่อมันแนะนำอนาคต

import numpy as np  # noqa: E402
import pandas as pd
from pathlib import Path

import os


def data_root() -> Path:
    """หาโฟลเดอร์ datasets/ — ใช้ได้ทั้ง repo local, venv และ Kaggle.

    ลำดับการค้นหา:
    1. environment variable COURSE_DATA_ROOT (ชี้ตรงไปที่โฟลเดอร์ datasets)
    2. โฟลเดอร์ datasets/ ที่อยู่ระดับเดียวกับโน้ตบุ๊กหรือแม่ขึ้นไป
       (repo local)
    3. /kaggle/input — ทั้งกรณีอัปโหลด datasets/ ทั้งโฟลเดอร์
       หรืออัปโหลดแต่ละชุดแยกกัน (ชื่อโฟลเดอร์ต้องตรงกับใน datasets/)
    """
    env = os.environ.get("COURSE_DATA_ROOT")
    if env:
        return Path(env)
    for p in (Path.cwd(), *Path.cwd().parents):
        if (p / "datasets").is_dir():
            return p / "datasets"
    kaggle = Path("/kaggle/input")
    if kaggle.is_dir():
        hits = sorted(kaggle.glob("**/datasets"))
        if hits:
            return hits[0]
        return kaggle
    raise SystemExit(
        "ไม่พบโฟลเดอร์ datasets/ — ตั้ง COURSE_DATA_ROOT "
        "หรือวาง datasets/ ไว้ข้างโน้ตบุ๊ก")

DATA = data_root()

ค่าความชัน (slope) คือสิ่งที่พูดให้คนฟังได้: "CO2 เฉลี่ยขึ้นปีละ ~2.4 ppm" — ตัวเลขหนึ่งตัวที่สรุป 570 เดือน

ก่อนเชื่อเส้นนี้ — ตรวจตามกติกา¶

ซ่อน 20% ท้ายไว้ ให้เส้นเรียนจากช่วงต้น แล้วทำนายช่วงท้ายที่ซ่อนไว้ เทียบกับของจริง วัดด้วย MAE (Mean Absolute Error — พลาดเฉลี่ยกี่หน่วย):

✏️ ลองเอง 3 — ทำนายค่า CO2 ในอนาคตด้วยสมการเส้นตรง¶

จากค่า slope และ intercept ของแนวโน้ม CO2 ที่คำนวณไว้ จงทำนายค่า CO2 ณ ปี ค.ศ. 2030 (ใช้ค่า x = 2030.0) แล้วพิมพ์ผลลัพธ์แบบทศนิยม 1 ตำแหน่ง

คำใบ้: ไวยากรณ์คำนวณสมการเส้นตรงคือ y = slope * x + intercept หรือใช้ np.polyval([slope, intercept], 2030.0)

cut = int(len(co2) * 0.8)          # 80% แรก = ฝึก, 20% ท้าย = สอบ
train = co2.iloc[:cut]
test = co2.iloc[cut:]

m, b = np.polyfit(train["decimal"], train["average"], 1)
pred = np.polyval([m, b], test["decimal"])
mae = (test["average"] - pred).abs().mean()
print(f"พยากรณ์ช่วงสอบ: พลาดเฉลี่ย {mae:.1f} ppm "
      f"(ของจริงอยู่ช่วง {test['average'].min():.0f}"
      f"–{test['average'].max():.0f})")

พยากรณ์ช่วงสอบ: พลาดเฉลี่ย 7.8 ppm (ของจริงอยู่ช่วง 403–429)

พลาดเฉลี่ย ~8 ppm บนช่วงข้อมูลกว้าง ~90 ppm — ราว 2% โดยรวมน่าเชื่อ สำหรับการทำนายช่วงสั้น แต่สังเกตให้เห็น: ช่วงสอบยาวถึง 9 ปี และช่วงท้าย เส้นตรงเริ่มตามไม่ทัน (CO2 เพิ่มเร่งขึ้น) — แม้กระทั่งข้อมูล "ขึ้นสม่ำเสมอ" แบบนี้ การยืดเส้นไกลก็เริ่มพลาดเพิ่มขึ้นเรื่อย ๆ

ข้อจำกัดที่ต้องพูดเสมอ: ทำนายได้ดีแค่ไหนขึ้นกับว่า "โลกยังเดินตามเส้นนี้ อีกแค่ไหน" — และนี่นำไปสู่กับดักใหญ่ที่สุดของโมดูลนี้...

✏️ ลองเอง 4 — ประเมิน MAE บนชุดฝึก (Train set)¶

คำนวณ MAE ระหว่างค่าจริง train["average"] กับค่าที่สมการเส้นตรงทำนายบนชุดฝึก pred_train = np.polyval([m, b], train["decimal"]) แล้วพิมพ์ค่า MAE ปัดเศษทศนิยม 1 ตำแหน่ง

คำใบ้: ไวยากรณ์วัด MAE คือ (train["average"] - pred_train).abs().mean() แล้วจัดรูปแบบด้วย f-string

2. กับดัก extrapolation — เส้นตรงไม่รู้จักโลกที่เปลี่ยน¶

ข้อมูลจริงไทย: นักท่องเที่ยวต่างชาติรายปี (สำนักงานปลัดกระทรวงการท่องเที่ยว และกีฬา) ลองใช้เทคนิคเดิม: วัดแนวโน้มจาก 2015–2019 แล้วยืดเส้นต่อไป:

In [11]:
tour = pd.read_csv(
    DATA / "tourist_arrivals" / "tourist_arrivals_by_country.csv")
yearly = tour.groupby("year")["tourist_number"].sum() / 1e6
history = yearly.loc[2015:2019]        # ก่อนโควิด — ขึ้นสวยมาก

m, b = np.polyfit(history.index, history, 1)
future = np.array([2020, 2021, 2022, 2023])
forecast = np.polyval([m, b], future)

fig, ax = plt.subplots(figsize=(7, 3.2))
yearly.plot.line(ax=ax, color="#457b9d", marker="o",
                 label="ของจริง")
ax.plot(future, forecast, "--", color="#e63946", lw=2,
        label="เส้นตรงจาก 2015–2019")
ax.legend()
ax.set_ylabel("นักท่องเที่ยว (ล้านคน)")
plt.show()

เส้นประสัญญาว่าปี 2020 ควรมีนักท่องเที่ยว ~41 ล้าน — ของจริงคือ 7 ล้าน (โควิด-19 ปิดโลกทั้งปี)

บทเรียนที่ยังอยู่กับผู้เรียนไปทั้งชีวิตทำงาน:

  • เส้นตรงเป็นแค่สมมติฐานว่า "อดีตจะต่อเนื่องไปถึงอนาคต" — ไม่ใช่คำสั่ง ของอนาคต
  • ยิ่งยืดไกลจากข้อมูล ยิ่งเชื่อไม่ได้ (พยากรณ์ 1-2 ช่วงต่อไป ≠ พยากรณ์ 5 ปี)
  • เมื่อเล่าให้ผู้บริหารฟัง ต้องบอกเงื่อนไขด้วย: "ถ้าทุกอย่างเดินตามดังเดิม"

ตัวเลขปี 2023 ของไฟล์นี้ยังไม่สมบูรณ์ (ระบบรายงานยังตามไม่ทัน ตัวเลขทางการ ~28 ล้าน) — อีกบทเรียน: ตรวจความครบถ้วนก่อนใช้ข้อมูลท้ายชุด

✏️ ลองเอง 5 — กับดัก Extrapolation: นักท่องเที่ยวปี 2020¶

คำใบ้: ค่าทำนายปี 2020 หาได้จาก np.polyval([m, b], 2020) ส่วนค่าจริงคือ yearly.loc[2020]

โบนัสไทย 1 — PM2.5: moving average ทำให้กราฟอ่านออก¶

✏️ ลองเอง 6 — Naive Forecast แบบ 1 เดือนย้อนหลัง¶

สร้างคอลัมน์ air["naive_1"] = air["value"].shift(1) แล้วคำนวณ MAE เทียบกับ air["value"] โดยตัดแถวแรกทิ้ง แล้วพิมพ์ค่า MAE ปัดเศษทศนิยม 1 ตำแหน่ง

คำใบ้: ไวยากรณ์คือ air["naive_1"] = air["value"].shift(1) และคำนวณ MAE ด้วย (air["value"].iloc[1:] - air["naive_1"].iloc[1:]).abs().mean()

4. เช็คลิสต์ "ควรเชื่อการพยากรณ์นี้ไหม" — 5 ข้อ¶

  1. ตรวจแล้วหรือยัง — ซ่อนท้าย ทำนาย เทียบจริง (MAE เล็กไหม?)
  2. ช่วงพยากรณ์สั้นกว่าช่วงข้อมูล — ข้อมูล 5 ปี พยากรณ์เดือนหน้า/ปีหน้า โอเค; พยากรณ์ 10 ปี ไม่โอเค
  3. โลกเปลี่ยนไหม — กฎ/เทคโนโลยี/พฤติกรรมเปลี่ยน = เส้นเก่าใช้ไม่ได้
  4. มีวงรอบ — จับวงรอบมาช่วย (เทียบปีก่อนเดือนเดียวกัน)
  5. พูดเงื่อนไข — "ถ้าทุกอย่างเดินตามดังเดิม" ต้องติดปากเสมอ
