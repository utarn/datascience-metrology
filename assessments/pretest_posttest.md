## ข้อสอบ

**ข้อ 1** ไฟล์ข้อมูล CSV ขนาด 1.5 ล้านแถว ต้องการนำมาสรุปยอดรายเดือน ข้อใดเป็นการประเมินสถานการณ์ที่ถูกต้อง

- ก. Excel เปิดไฟล์นี้ได้ครบทุกแถว เพราะ Excel รองรับจำนวนแถวไม่จำกัด
- ข. Excel โหลดได้เพียง 1,048,576 แถวแรก ข้อมูลที่เหลือจะไม่ถูกโหลด จึงควรโหลดด้วย Python (pandas) แล้วสรุปตรงนั้น
- ค. ต้องแปลงไฟล์เป็น JSON ก่อนเสมอ มิฉะนั้น Python จะอ่านไม่ได้
- ง. ควรลบแถวส่วนเกินทิ้งให้เหลือไม่เกินหนึ่งล้านแถว แล้วจึงเริ่มวิเคราะห์

**ข้อ 2** ตัวแปรราคาเก็บค่า `"9.50"` (มีเครื่องหมายคำพูดคลุม) และตัวแปรจำนวนเก็บค่า 3 เมื่อสั่งให้คูณกันแล้วเกิด error ข้อใดอธิบายสาเหตุได้ถูกต้อง

- ก. เครื่องคำนวณไม่รองรับเครื่องหมายจุดทศนิยม
- ข. `"9.50"` เป็นข้อความ (str) ไม่ใช่ตัวเลข (float) Python จึงนำไปคูณไม่ได้จนกว่าจะแปลงชนิดข้อมูลให้ตรงกัน
- ค. จำนวน 3 ต้องมีเครื่องหมายคำพูดคลุมด้วยจึงจะคูณได้
- ง. Python คูณตัวเลขสองค่าด้วยกันไม่ได้ ต้องใช้ Excel เท่านั้น

**ข้อ 3** สรุปยอดขายตามภูมิภาคด้วย groupby ได้ตารางดังนี้

| ภูมิภาค | จำนวนรายการ | ยอดขายเฉลี่ย |
|---|---|---|
| เหนือ | 120 | 8,400 |
| กลาง | 350 | 12,100 |
| ใต้ | 95 | 7,900 |

ข้อใดแปลผลตารางนี้ได้ถูกต้อง

- ก. แต่ละแถวคือสรุปของกลุ่มหนึ่งกลุ่ม — มาจากการแบ่งตารางเป็นกองตามภูมิภาค คำนวณแต่ละกอง แล้วรวมกลับเป็นตารางเดียว
- ข. แต่ละแถวคือรายการข้อมูลดิบหนึ่งรายการ
- ค. แถวแรกคือผลรวมของทุกภูมิภาครวมกัน
- ง. ตารางนี้เรียงแถวจากยอดขายมากไปน้อยโดยอัตโนมัติ

**ข้อ 4** คอลัมน์ "ความสูง" มีค่าตัวอย่างดังนี้: `1450 msnm` · `1000 meters` · `1200 - 1500` ข้อใดอธิบายปัญหาและผลที่ตามมาได้ถูกต้อง

- ก. ไม่มีปัญหา — pandas คำนวณค่าเฉลี่ยของคอลัมน์นี้ได้ปกติ
- ข. หน่วยปนอยู่ในคอลัมน์เดียว ทำให้ pandas เก็บทั้งคอลัมน์เป็นข้อความ คำนวณค่าเฉลี่ยตรง ๆ ไม่ได้ ต้องคัดตัวเลขออกจากข้อความก่อน
- ค. ปัญหาคือมีค่าว่าง ควรลบแถวเหล่านี้ทิ้งทั้งหมด
- ง. ต้องแปลเป็นภาษาอังกฤษทั้งคอลัมน์ก่อน จึงจะคำนวณได้

**ข้อ 5** คอลัมน์ "อายุ" มีค่า `?` ปนอยู่ 12 ช่อง แต่การนับค่าว่าง (`isna().sum()`) ยังรายงานค่าว่างเป็น 0 เพราะเหตุใด

- ก. เพราะ pandas นับ `?` เป็นค่าว่างอยู่แล้ว — ผลเป็น 0 แปลว่าไม่มีปัญหาค่าหาย
- ข. เพราะ `?` ถูกมองเป็นข้อความธรรมดา ไม่ใช่ค่าว่างมาตรฐาน (NaN) — ต้องแทนที่ด้วย NaN ก่อน ตัวนับจึงจะมองเห็น
- ค. เพราะการนับค่าว่างใช้กับคอลัมน์ตัวเลขไม่ได้
- ง. เพราะต้องเรียงตารางก่อน จึงจะนับค่าว่างได้

**ข้อ 6** มีข้อมูลความยาวครีบและน้ำหนักของเพนกวินหลายร้อยตัว ต้องการดูว่าสองค่านี้เคลื่อนไหวสัมพันธ์กันหรือไม่ ควรเลือกกราฟชนิดใด

- ก. กราฟแท่ง (bar)
- ข. กราฟเส้น (line)
- ค. กราฟจุดกระจาย (scatter)
- ง. histogram

**ข้อ 7** กราฟแท่งเปรียบเทียบยอดสามกลุ่ม (3,050 / 3,010 / 3,040) วาดโดยให้แกน y เริ่มที่ 3,000 แท่งกลุ่มแรกจึงดูสูงกว่าอีกสองกลุ่มหลายเท่า ข้อใดประเมินกราฟนี้ได้ถูกต้อง

- ก. กลุ่มแรกต่างจากกลุ่มอื่นอย่างมากมาย เพราะแท่งสูงกว่าหลายเท่า
- ข. กราฟนี้ถูกต้องแล้ว เพราะตัวเลขบนกราฟเป็นจริงทุกแท่ง
- ค. แกนตัดฐาน (ไม่เริ่มที่ศูนย์) ขยายความต่างเท็จ — กราฟแท่งวัดด้วยความยาวแท่ง ควรเริ่มแกนที่ศูนย์ ความต่างจริงของสามกลุ่มนี้แทบไม่ต่างกัน
- ง. ควรเปลี่ยนเป็นกราฟเส้นแล้วปัญหานี้จะหายไป

**ข้อ 8** สรุปคอลัมน์ "เวลารอคอย" (นาที) ได้ดังนี้: จำนวน 200 · ค่าเฉลี่ย 30.2 · std 12.5 · ต่ำสุด 4 · 25% 21.0 · **50% 28.0** · 75% 37.5 · สูงสุด 95 ข้อใดแปลผลถูกต้อง

- ก. ค่า 50% = 28.0 หมายถึงครึ่งหนึ่งของข้อมูลมีเวลารอไม่เกิน 28 นาที
- ข. ค่า 50% หมายถึงผลรวมของข้อมูลเป็นครึ่งหนึ่งของค่าสูงสุด
- ค. เวลารอทั้งหมดอยู่ระหว่าง 25 ถึง 75 นาที
- ง. ค่าสูงสุด 95 นาทีไม่มีผลต่อค่าเฉลี่ยเลย

**ข้อ 9** เงินเดือนพนักงาน 7 คน: 20,000 บาท 6 คน และ 200,000 บาท 1 คน ต้องการรายงาน "เงินเดือนทั่วไปของพนักงาน" ข้อใดเลือกตัวเลขและเหตุผลได้ถูกต้อง

- ก. ใช้ค่าเฉลี่ย (mean) เพราะเป็นตัวเลขมาตรฐานที่ทุกคนคุ้นเคยที่สุด
- ข. ใช้ค่ากึ่งกลาง (median) เพราะค่าสุดขอบ (outlier) ลาก mean ให้สูงจนไม่ตรงกับเงินเดือนของคนส่วนใหญ่
- ค. ใช้ค่าสูงสุด เพราะแสดงศักยภาพสูงสุดของอัตราเงินเดือน
- ง. ใช้ค่าเฉลี่ย แต่ตัดคนรายได้สูงออกจากข้อมูลโดยไม่ต้องแจ้งผู้อ่านรายงาน

**ข้อ 10** กราฟจำนวนนักท่องเที่ยว 5 ปีมีแนวขาขึ้นสวยงาม วาด trend line แล้วยืดเส้นไปพยากรณ์อีก 2 ปีข้างหน้า ผู้บริหารถามว่า "เชื่อผลนี้ได้แค่ไหน" ข้อใดตอบได้ถูกต้อง

- ก. เชื่อได้เต็มร้อย เพราะเส้นตรงคำนวณจากข้อมูลจริงทั้งหมด
- ข. ไม่ควรเชื่อแบบไม่ตรวจ — เส้นตรงเป็นสมมติฐานว่า "อดีตต่อเนื่องไปถึงอนาคต" เมื่อโลกเปลี่ยน (เหตุการณ์ กฎ พฤติกรรม เช่นช่วงโควิดกับนักท่องเที่ยว) เส้นพังทันทีและพังอย่างเงียบ ควรตรวจด้วยการซ่อนช่วงท้าย–ทำนาย–เทียบกับของจริง และบอกขอบเขตการพยากรณ์กับผู้ฟังเสมอ
- ค. ยิ่งยืดเส้นไปไกลเท่าไร ยิ่งแม่นยำขึ้นเท่านั้น
- ง. เส้นตรงกับ moving average ให้ผลพยากรณ์เหมือนกันเสมอ จึงไม่ต้องสนใจว่าเลือกใช้อะไร
