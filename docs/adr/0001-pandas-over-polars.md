# ADR-0001: ใช้ pandas แทน Polars ในหลักสูตร 2 วัน

วันที่: 2026-10-01 (บันทึก) · สถานะ: accepted

## บริบท

`NEXT_COURSE.md` (ใน OneDrive โฟลเดอร์ "อบรม ML in Metrology") บันทึกไว้ว่าคอร์ส 2 วันสอน **Polars** ตามคอร์สมาตรวิทยาเดิม (docx) ที่ยกเหตุผล "data logger ขนาดใหญ่ ต้องการ multi-threading" และระบุไว้แล้วว่าเป็นข้อตัดสินใจค้าง เพราะคอร์ส 3 วันใช้ pandas

## การตัดสินใจ

ใช้ **pandas** เป็นไลบรารีตารางหลักของหลักสูตร 2 วัน

## เหตุผล

1. ผลสำรวจโน้ตบุ๊กจริงของ ml-metrology (2026-10-01): pandas ถูกใช้ใน 6/9 โน้ตบุ๊ก + ทั้ง 3 capstone starters (อ่าน CSV, ตารางสรุปผล) — **Polars ถูก pin ไว้แต่ไม่มีเซลล์ไหนใช้เลย** (dependency ตาย) คอร์สต่อยอดที่ "สมมติว่าผู้เรียนรู้มาแล้ว" คือ pandas
2. เหตุผลเดิมของ Polars (ข้อมูล data logger ขนาดใหญ่เชิงมาตรวิทยา) หายไป เมื่อเนื้อหาเป็นกลางและขนาดชุดข้อมูลเล็กพอรันเครื่องผู้เรียน
3. ผู้เริ่มต้นเจอ pandas มากกว่าในแหล่งเรียนรู้/คำถามจริงภายหลัง

## ผลตามมา

- ตัด Polars ออกจาก dependency ของ repo นี้
- ข้อความใน `NEXT_COURSE.md` (อีก repo) ที่ยังพูดถึง Polars ถือเป็นล้าสมัย — อย่าอ้างอิงตอนออกแบบสื่อ
- ข้อตัดสินใจค้าง "Polars vs pandas" ใน NEXT_COURSE.md ปิดแล้วด้วย ADR นี้
