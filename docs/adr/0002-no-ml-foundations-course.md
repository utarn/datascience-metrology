# ADR-0002: หลักสูตร 2 วันเป็น foundations แบบไม่มี ML — ห้ามสอน Machine Learning ทุกประเภท

วันที่: 2026-10-01 (บันทึก) · สถานะ: accepted

## บริบท

คอร์ส DS 2 วันเดิม (docx "โครงการฝึกอบรม Data Science สำหรับนักมาตรวิทยา 2") มีโมดูลซ้ำหนักกับคอร์ส ML 3 วัน (drift prediction = regression ด้วย scikit-learn ทั้งชุด) `NEXT_COURSE.md` ตัดสินใจเปลี่ยน positioning ทั้งหมด (2026-09-30) แต่ข้อความ "โมเดลขนาดเล็ก" ในคำขอออกแบบยังกำกวมได้ว่ารวม ML เล็ก ๆ หรือไม่

## การตัดสินใจ

ยืนยันกติกาเหล็ก: **ห้ามสอน ML ทุกประเภท** (regression/classification/clustering/anomaly, scikit-learn, train/test split, model evaluation) ในหลักสูตร 2 วัน — "โมเดลขนาดเล็ก" ในที่นี้หมายถึง **พยากรณ์แบบไม่ใช้ ML**: trend line, moving average, regression เส้นตรงในฐานะสถิติ (เส้นพอดี ไม่ใช่การเทรนโมเดล)

## เหตุผล

1. ผลสำรวจ ml-metrology (2026-10-01) ยืนยันว่าคอร์ส 3 วันสมมติผู้เรียนรู้ train/test, overfitting, metrics มาแล้ว (M0 เป็น refresher) — คอร์ส 2 วันคือผู้สอนเรื่องนั้นให้ก่อน การใส่ ML ซ้ำทำให้สองคอร์สกลายเป็นคู่แข่ง
2. ขอบเขต EDA/สถิติ/กราฟทั้งหมดยังว่างในคอร์ส 3 วัน — คอร์ส 2 วันเป็นเจ้าของดินแดนนั้นเพียงผู้เดียว

## ผลตามมา

- ห้าม import scikit-learn ในสื่อของคอร์สนี้
- ต้องสอนกับดัก extrapolation เสมอในช่วงพยากรณ์
- ปิดคอร์สด้วยสไลด์ "What's next" เชื่อมไปคอร์ส ML 3 วัน (Python + ข้อมูลสะอาด + แนวโน้ม = วัตถุดิบของ ML)
